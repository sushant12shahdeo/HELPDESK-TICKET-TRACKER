# HELPDESK-TICKET-TRACKER

An Excel-based helpdesk management project for tracking customer support tickets, status, priority, escalations, and resolution time.

## Features

- Ticket tracking and categorization
- Priority and status management
- Escalation tracking
- Automatic Days to Resolve calculation
- FAQ and troubleshooting guide
- PivotTables and summary dashboard
- Ticket and resolution analysis

## Excel Skills Used

- Excel Tables
- IF formulas
- Conditional Formatting
- PivotTables
- PivotCharts
- Data Analysis
- Data Visualization

## Project Summary

The workbook contains **40 support tickets** across categories such as Google Ads, Account Access, Excel Reporting, Billing/Budget, Conversion Tracking, and Web/HTML.

**Tools:** Microsoft Excel  
**Project Type:** Helpdesk / Data Analysis
